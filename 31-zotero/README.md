## Motivation
Student prefer to write the paper in LaTeX, but Teacher prefer to review in Word.

## Solved problem:
Copying a paper from Word to LaTeX is time consuming, e.g copying a paragraph:
1. Copy the paragraph to LaTeX.
2. Look at the references list in the Word APP and then replace e.g. `[citation number]` to `\cite{citekeys}`.

## Use Case:
This enables inline citations copy from Word to LaTeX

## Note:
This does not enable inline citations copy from LaTeX to Word. However, this is a non issue as you can just copy the citekeys to Zotero Word plugin in the Word APP.

## Installation:
1. Open the Zotero APP, then select the Cite tab, and add the Better BibTeX Citekeys
2. Open the Word APP, then select the Zotero tab, select the Document Preferences button, and change the citation style to Better BibTeX Citekeys
